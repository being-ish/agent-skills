# Skill 遵守チェック

セッションで使った Skill と成果物を突き合わせ、違反があれば修正する。

## 手順

1. このセッションで使った Skill と、作成、変更したファイルを列挙する
    - ユーザーが対象を指定していればそれに従う
2. Task ツールで `skill-adherence:skill-adherence-checker` sub-agent を起動する
    - 使用 Skill 名と成果物ファイルのパス一覧をプロンプトで渡す
3. 報告された違反を成果物に反映する
    - 修正内容もまた Skill に沿っているか注意する
4. 違反がなければその旨をユーザーに伝えて終了する
