# タイトル

## 概要

この runbook が扱うインシデントを 2、3 文で書く。

## 検知

- このインシデントに気づく経路を列挙する
- アラートがあるなら、アラート名と定義へのリンクを書く
- アラートがないなら、利用者からの申告やダッシュボードの目視など気づく経路を書く

## 対処前チェック

- インシデントを確認するコマンドやダッシュボード
- 切り分けの分岐と、その判断基準
- 切り分けの結果が別のインシデントだったときは、該当する runbook へリンクする

## 対処

1. 対処の手順を 1 つずつ書く
    - 実行するコマンドを `command` の形で書く
    - 期待する結果として、何が出れば復旧かを書く
2. 対処できなかった場合はエスカレーションへ進む

## エスカレーション

- エスカレーションする判断基準
- 連絡先と連絡手段
- 伝える情報

## 事後対応

- 記録を残す場所
- 再発防止策の検討と Issue の起票
