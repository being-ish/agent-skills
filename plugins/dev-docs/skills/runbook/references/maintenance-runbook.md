# タイトル

## 概要

この作業でやることを 2、3 文で書く。

## 実施タイミング

- 頻度、実施する条件
- 実施してはいけない時間帯があれば書く

## 前提条件

- 必要な権限、認証情報の入手方法
- 事前に確認しておく状態
- 関係者への事前連絡の要否

## 手順

1. 手順を 1 つずつ書く
    - 実行するコマンドを `command` の形で書く
    - 期待する結果として、何が出れば成功かを書く
    - 失敗したときの分岐を書く
        - ロールバックする条件と、元の状態へ戻す操作をその場に書く
        - 戻さず次へ進める失敗なら、その判断基準を書く
    - 元に戻せない操作は、実行前にその旨を明記する
2. 判断が要る箇所は判断基準を明記する

## 作業後の確認

- 確認する項目と、正常とみなす値
- 確認に使うダッシュボードやコマンド
