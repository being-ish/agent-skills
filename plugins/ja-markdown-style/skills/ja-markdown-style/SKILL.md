# 日本語 Markdown スタイルガイド

日本語で Markdown 文書を書く、直すときの指針。

機械的に白黒を付けられる規則は同プラグインの PostToolUse Hook が検査する。
このスキルは、Hook では判定できない、書き手の判断が必要な指針を扱う。

## 文書種別

frontmatter の `being-ish` 配下に `kind` を書くと、その種別に合わない検査を Hook が省く。

```markdown
---
being-ish:
  kind: legal
---
```

種別には次がある。

- `legal`、法文書は条文の慣行に従うため次の規則を適用しない
    - 箇条書き内で句点 `。` を使わない

指定がない場合と一覧にない種別を指定した場合は、すべての検査を適用する。

## 前提確認

- 対象読者を想定する
    - 指示や既存文書に手がかりがあればそれを仮定し、ユーザーに報告する
    - 手がかりがない場合は推測せずユーザーに確認する

## 文章内容の指針

- 常に最新の情報を書く
    - カットオフ時の知識のみで書かない
- 対象読者がすでに知っているであろう知識は書かない

## 文章構成の指針

- 非常に簡潔に短く書く
- 木下是雄「理科系の作文技術」に則って出力する
    - 逆茂木型の文章を避ける
        - 結論を先に短く
        - 根拠を続けて、端的に書く
    - トピックは対象読者がわかりやすい順番に並べる
    - 括弧での補足を使わない
        - 必要な情報は地の文に書く
- 同じ情報を複数個所に書かない
    - 前後のつながりが自然なところに書き、他からは参照する

## 書き方の指針

- 造語を使わない
    - 正式な用語か一般的な言葉のみ使う
- [カタカナ外来語の表記は文化庁準拠](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/gairai/index.html)とする
    - 末尾長音を付ける
- 出典は末尾に列挙せず、本文の該当語句にインラインリンクを張る
    - インラインリンクを張るときは出典名をアンカーテキストにしない
- 文中列挙の区切りは中黒 `・` でなく読点 `、` を使う
    - 固有名詞に含まれる中黒はそのまま書く
    - カタカナで書く人名は姓名の区切りに中黒を使う
    - 法文書は条文の慣行に従うため中黒を使って良い
- 対応関係は表にする
- 列挙できる内容は箇条書きを使う
    - 箇条書きのネストのインデントは半角スペース 4 とする
- `**太字**` を基本使わない
    - 強調しないと想定読者に意図が伝わらない箇所だけ使う
    - コード識別子は `バッククォート` で足りる
